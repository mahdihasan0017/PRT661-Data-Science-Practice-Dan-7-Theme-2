# Project Planning Records

This folder combines the initial proposal with an updated final-scope plan. The project-management folder contains the operational records required by the brief:

- task list and completion status;
- milestone/sprint plan;
- team-role allocation;
- progress and evidence paths;
- scope-change log;
- project timeline; and
- collaboration-evidence template for genuine GitHub/Jira/Trello/Notion records.

**Important:** The task/milestone records in this package are reconstructed from the submitted proposal and final implementation artefacts. They are not a substitute for real historical board activity, commits or pull requests. Add genuine collaboration links/screenshots before assessment submission if your lecturer requires them.
