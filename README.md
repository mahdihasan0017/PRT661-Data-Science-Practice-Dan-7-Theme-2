# Project Management Evidence

The unit requires use of at least one professional project-management platform (e.g., Jira, GitHub Projects, Trello, Notion or Azure DevOps Boards). The CSV/Markdown files here make the final scope and status explicit and can be used to populate or reconcile the selected board.

**Do not present reconstructed files as historical collaboration evidence.** Real board URLs, commit links, pull requests, issue activity or screenshots must come from the team's actual platform.
